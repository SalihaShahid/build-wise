# Completion

Use this checklist before declaring a task complete.

## Implementation

- [ ] Task requirements understood.
- [ ] Acceptance criteria understood.
- [ ] Relevant code inspected.
- [ ] Existing test conventions followed.
- [ ] Required behavior implemented.
- [ ] No unnecessary scope expansion.

## TDD

- [ ] Tests were written before corresponding implementation.
- [ ] New tests initially failed for the expected reason.
- [ ] Minimum implementation was added.
- [ ] New tests pass.
- [ ] Refactoring was performed where appropriate.
- [ ] Tests remain passing after refactoring.

## Verification

- [ ] New tests pass.
- [ ] Modified tests pass.
- [ ] Related tests pass.
- [ ] Regression tests pass.
- [ ] Broader test suite run when practical.
- [ ] Acceptance criteria are satisfied.
- [ ] No known task-related failures remain.

## Reporting

Report:

- What was implemented.
- What tests were added or changed.
- What tests were executed.
- Test results.
- Any limitations or blockers.
- Any genuinely separate follow-up work.
